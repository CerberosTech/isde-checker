# ISDE-checker
Static Dutch site: is my heat pump on RVO's ISDE meldcodelijst? `node build.mjs` → `dist/`. No dependencies.
English version under `/en/` (same data, translated templates; guides from `content/guides-en/`, paired with the Dutch guides in `GUIDE_PAIRS` in `build.mjs`). Every page has hreflang nl/en/x-default and a language switch.
The model index is split into one page per first letter of the brand (`/warmtepomp/a/`, `/en/heat-pumps/a/`). Model, brand, list and home pages show the RVO list date: the `dcterms:modified` date in the xlsx, never the build date. The same date is the Dataset `dateModified` in the JSON-LD and the sitemap `<lastmod>`; guides use their `updated:` front matter.
About page: `/over/` from `content/about/over.md` and `/en/about/` from `content/about-en/about.md` (same markdown as the guides; sitemap `lastmod` is `ABOUT_UPDATED` in `build.mjs`). Affiliate links and calls to action carry `data-goatcounter-click` names (`bol-…`, `search-…`, `copy-meldcode`, `rvo-isde-apply`). The footer lists four other CerberosTech tools as plain links.
Check the build (routes, hreflang, sitemap, internal links, JSON-LD, list date, page sizes, pagination, GoatCounter script and click names): `node scripts/check-site.mjs`. The four sister-tool footer links: `node scripts/check-footer-links.mjs`.
Data: RVO ISDE Meldcodelijst Warmtepompen (open government info, reuse allowed per rvo.nl/onderwerpen/open-data). Fetched at build time, fallback to `data/rvo.xlsx`.
Brand kit (logo, icons, og-image): see `brand/BRAND.md`. Regenerate into `src/` with `node brand/build-brand.mjs` (needs Chrome or Chromium).
